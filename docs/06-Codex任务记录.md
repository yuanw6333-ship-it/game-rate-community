# GameRate Codex 任务记录

本文档用于记录每次与 Codex 协作的任务输入、修改范围、人工检查和后续计划，方便项目持续迭代和复盘。

## 记录规范

- 每次任务完成后追加一条记录。
- 任务目标要尽量明确，不记录模糊描述。
- 修改文件必须列出相对路径。
- 人工检查结果要写清楚是否通过。
- 如果没有测试，也要说明原因。
- 如果任务未提交 Git，需要说明原因。
