## 3. RAWG 游戏资料导入模块测试项

RAWG 接口属于后台接口，测试前需要先调用 `POST /api/user/login` 获取 Token，并在 Postman 请求头中增加：

```text
Authorization: Bearer <token>
```

同时需要在本地环境中配置 `RAWG_API_KEY`，不要把真实 Key 写入代码或提交到 Git。

### 当前联调结果

| 项目 | 结果 |
|---|---|
| 本地后端启动 | 可以正常启动 |
| RAWG API Key | 已配置 |
| Postman 请求后台 RAWG 搜索接口 | 后端返回 `RAWG request timeout or network error` |
| PowerShell `curl.exe` 直接请求 RAWG API | 请求 `https://api.rawg.io/api/games` 时返回 `Failed to connect to api.rawg.io port 443` |
| 初步结论 | 本地网络无法连接 `api.rawg.io:443`，不属于业务代码问题 |
| 后续处理 | 保留 RAWG 模块，后续在网络环境稳定或部署到云服务器后重新测试 |
