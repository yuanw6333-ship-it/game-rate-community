## 3. RAWG 游戏资料导入模块测试项

RAWG 接口属于后台接口，测试前需要先调用 `POST /api/user/login` 获取 Token，并在 Postman 请求头中增加：

```text
Authorization: Bearer <token>
```

同时需要在本地环境中配置 `RAWG_API_KEY`，不要把真实 Key 写入代码或提交到 Git。

### 当前联调结果

| 项目 | 结果 |
|---|---|
| 本地后端启动 | 可以正常启动 |
| RAWG API Key | 已配置 |
| Postman 请求后台 RAWG 搜索接口 | 后端返回 `RAWG request timeout or network error` |
| PowerShell `curl.exe` 直接请求 RAWG API | 请求 `https://api.rawg.io/api/games` 时返回 `Failed to connect to api.rawg.io port 443` |
| 初步结论 | 本地网络无法连接 `api.rawg.io:443`，不属于业务代码问题 |
| 后续处理 | 保留 RAWG 模块，后续在网络环境稳定或部署到云服务器后重新测试 |

### 3.3 导入 RAWG 游戏

| 项目 | 内容 |
|---|---|
| 接口 | `POST /api/admin/rawg/import` |
| 是否需要登录 | 是 |
| 前置条件 | 已登录并获取 Token；分类和平台数据已初始化；已配置 RAWG API Key |
| 请求体示例 | `{"rawgId": 3328, "categoryId": 1, "platformId": 1, "status": 1, "overwrite": false}` |
| 预期结果 | 写入本地 `game` 表，返回本地 `gameId`，`source_type=RAWG`，`source_id=rawgId` |
| 测试结果 | 待测试 |

验证点：

- `description` 已简单去除 HTML 标签。
- `average_score`、`rating_count`、`view_count`、`favorite_count`、`comment_count` 默认 0。
- `last_sync_time` 写入当前时间。
- 重复导入同一个 `rawgId` 时不新增数据，返回已有 `gameId`。

异常场景：

- 未携带 Token。
- `categoryId` 不存在。
- `platformId` 不存在。
- RAWG API 请求失败。
