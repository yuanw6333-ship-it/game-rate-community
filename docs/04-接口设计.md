# GameRate 游戏评分社区 V1 接口设计

## 1. 接口通用约定

- 接口风格：RESTful API
- 请求前缀：`/api`
- 请求格式：`application/json`
- 返回格式：统一 JSON
- 认证方式：V1 建议使用 Token 或 JWT，具体实现阶段再确定。
- 分页参数：列表接口统一使用 `page` 和 `pageSize`。
- 权限说明：游客、登录用户、管理员。

### 通用返回结构

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

## 2. 用户接口

### 2.1 用户注册

| 项目 | 内容 |
|---|---|
| 接口说明 | 注册普通用户账号 |
| 请求方式 | POST |
| 请求路径 | `/api/users/register` |
| 请求参数 | `username`、`password`、`nickname` |
| 返回数据说明 | 返回用户ID、用户名、昵称 |
| 权限要求 | 游客 |

### 2.2 用户登录

| 项目 | 内容 |
|---|---|
| 接口说明 | 用户登录并获取登录凭证 |
| 请求方式 | POST |
| 请求路径 | `/api/users/login` |
| 请求参数 | `username`、`password` |
| 返回数据说明 | 返回 Token、用户ID、用户名、昵称、角色 |
| 权限要求 | 游客 |

### 2.3 获取当前用户信息

| 项目 | 内容 |
|---|---|
| 接口说明 | 获取当前登录用户资料 |

| 请求参数 | 无 |
| 返回数据说明 | 返回用户ID、用户名、昵称、头像、简介、角色 |
| 权限要求 | 登录用户 |

### 2.4 修改当前用户信息

| 项目 | 内容 |

| 返回数据说明 | 返回修改后的用户资料 |
| 权限要求 | 登录用户 |

### 2.5 用户退出登录

| 项目 | 内容 |
|---|---|

| 请求方式 | POST |

## 4. 评分接口

### 4.1 新增评分

| 项目 | 内容 |
|---|---|
| 接口说明 | 当前用户对指定游戏评分 |
| 请求方式 | POST |
| 请求路径 | `/api/games/{gameId}/scores` |
| 请求参数 | 路径参数 `gameId`，请求体 `score`、`content` |
| 返回数据说明 | 返回评分记录和游戏最新评分统计 |
| 权限要求 | 登录用户 |

### 4.2 修改评分

| 项目 | 内容 |
|---|---|
| 接口说明 | 当前用户修改自己对指定游戏的评分 |
| 请求方式 | PUT |
| 请求路径 | `/api/games/{gameId}/scores` |
| 请求参数 | 路径参数 `gameId`，请求体 `score`、`content` |
| 返回数据说明 | 返回更新后的评分记录和游戏最新评分统计 |
| 权限要求 | 登录用户 |

### 4.3 删除评分

| 项目 | 内容 |
|---|---|
| 接口说明 | 当前用户删除自己对指定游戏的评分 |
| 请求方式 | DELETE |
| 请求路径 | `/api/games/{gameId}/scores` |
| 请求参数 | 路径参数 `gameId` |
| 返回数据说明 | 返回删除结果和游戏最新评分统计 |
| 权限要求 | 登录用户 |

### 4.4 查询游戏评分列表

| 项目 | 内容 |
|---|---|
| 接口说明 | 分页查询指定游戏的评分和短评 |
| 请求方式 | GET |
| 请求路径 | `/api/games/{gameId}/scores` |
| 请求参数 | 路径参数 `gameId`，查询参数 `page`、`pageSize` |
| 返回数据说明 | 返回评分分页列表、平均分、评分人数 |
| 权限要求 | 游客 |
