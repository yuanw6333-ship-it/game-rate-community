# GameRate 游戏评分社区 V1 项目规划

## 1. 项目背景

GameRate 是一个面向游戏玩家的游戏评分、评论、排行榜、收藏和讨论社区。游戏玩家在选择游戏前，通常需要查看游戏基础信息、玩家评分、评论反馈和热门排行；在游玩之后，也希望能够记录自己的评分、发表评价并收藏感兴趣的游戏。

本项目适合作为 Java 后端、Web 前端、小程序端的综合练习项目。它既包含常见的用户登录、列表分页、详情查询、评分统计、评论管理、收藏管理等后端能力，也能延伸到 Vue 3 Web 页面、后台管理页面和微信小程序端。

项目后续可以作为个人简历项目展示，体现完整项目规划、数据库设计、RESTful API 设计、前后端联调、部署上线和持续迭代能力。

## 2. 项目目标

- 搭建一个完整但规模可控的游戏评分社区。
- 支持游戏信息浏览，包括游戏列表、详情、分类、平台、标签等。
- 支持用户注册、登录、退出登录和个人资料维护。
- 支持用户对游戏评分，并统计平均分和评分人数。
- 支持用户发表评论，并支持评论分页和基础管理。
- 支持用户收藏游戏，并查看我的收藏列表。
- 支持游戏排行榜，包括高评分、热门评论、最新发布和收藏排行。
- 支持后台管理基础数据，包括游戏、分类、标签和评论。
- 后续支持微信小程序端访问核心功能。

## 3. 目标用户

- 普通游戏玩家：浏览游戏信息、查看评分和评论。
- 想查看游戏评分的用户：通过排行榜、搜索和详情页辅助选游戏。
- 想发表游戏评价的用户：对玩过的游戏打分、评论、收藏。
- 项目管理员：维护游戏资料、分类、标签和评论内容。

## 4. V1 版本范围

V1 只做核心功能，避免一次性扩展成大型社区。

- 用户注册登录。
- 游戏列表。
- 游戏详情。
- 游戏评分。
- 游戏评论。
- 游戏收藏。
- 游戏排行榜。
- 后台游戏信息管理。
- 基础搜索。
- Web 端基础页面。
- 小程序端预留目录和后续接口规划。

## 5. 暂不实现的功能

- 即时聊天。
- 复杂推荐算法。
- 复杂社区动态流。
- 支付系统。
- 大规模数据爬虫。
- 第三方账号登录。
- 复杂权限系统。
- 游戏百科级数据维护。

## 6. 项目阶段规划

### 阶段一：文档和项目框架

- 创建项目目录结构。
- 补充项目规划、功能模块、数据库设计、接口设计和开发流程文档。
- 明确 V1 版本边界，避免开发范围失控。

### 阶段二：数据库设计

- 设计 V1 核心数据表。
- 明确表关系、索引和可扩展字段。
- 编写初始化建表脚本和基础数据脚本。

### 阶段三：后端基础配置

- 初始化 Spring Boot 后端工程。
- 配置 MyBatis-Plus、MySQL、统一返回格式、异常处理和接口文档。
- Redis 在前期只预留，不作为 V1 强依赖。

### 阶段四：用户模块

- 实现用户注册、登录、退出登录。
- 实现获取当前用户信息和修改个人资料。
- 区分普通用户和管理员身份。

### 阶段五：游戏信息模块

- 实现游戏列表、详情、分类、标签、平台筛选。
- 实现后台新增、修改、删除游戏。
- 维护游戏封面、简介、厂商、发行日期等基础信息。

### 阶段六：评分评论模块

- 实现用户评分、修改评分、删除评分。
- 实现评论发布、列表分页、删除评论。
- 更新游戏平均分、评分人数、评论数量等统计字段。

### 阶段七：排行榜和搜索

- 实现高评分榜、热门评论榜、最新发布榜和收藏数榜。
- 实现按名称、分类、标签、平台的基础搜索和筛选。

### 阶段八：前端页面

- 开发 Web 用户端基础页面。
- 开发后台管理基础页面。
- 完成前后端接口联调。

### 阶段九：小程序端

- 先预留微信小程序或 uni-app 目录结构。
- 后续实现首页、游戏列表、游戏详情、评分评论、收藏和个人中心。

### 阶段十：部署上线

- 准备服务器环境。
- 部署 MySQL、Redis、后端 jar、前端 dist 和 Nginx。
- 完成线上访问、接口联调、日志查看和基础备份。
