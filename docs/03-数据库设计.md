# 03 数据库设计

## 数据库说明

- 数据库名称：`gamerate`
- 数据库类型：MySQL
- 字符集：`utf8mb4`
- 排序规则：`utf8mb4_unicode_ci`
- V1 目标：支持用户、管理员、游戏资料、分类、平台、评分、评论、收藏等核心功能。
- 删除策略：所有业务表预留 `deleted` 字段做逻辑删除。
- 时间字段：统一使用 `create_time` 和 `update_time` 记录创建、更新时间。

## 核心数据表

| 表名 | 作用 |
|---|---|
| `user` | 保存普通用户账号、昵称、头像、联系方式和账号状态 |
| `admin` | 保存后台管理员账号、角色和账号状态 |
| `category` | 保存游戏分类，如动作、角色扮演、策略等 |
| `platform` | 保存游戏平台，如 PC、Steam、PlayStation 等 |
| `game` | 保存游戏基础资料、评分统计、评论数、收藏数和数据来源 |
| `game_rating` | 保存用户对游戏的评分记录 |
| `game_comment` | 保存用户对游戏的评论记录 |
| `game_favorite` | 保存用户收藏游戏的记录 |

## 表关系

| 关系 | 说明 |
|---|---|
| `game.category_id -> category.id` | 一个游戏对应一个主分类 |
| `game.platform_id -> platform.id` | 一个游戏对应一个主平台 |
| `game_rating.user_id -> user.id` | 一条评分属于一个用户 |
| `game_rating.game_id -> game.id` | 一条评分属于一个游戏 |
| `game_comment.user_id -> user.id` | 一条评论属于一个用户 |
| `game_comment.game_id -> game.id` | 一条评论属于一个游戏 |
| `game_favorite.user_id -> user.id` | 一条收藏属于一个用户 |
| `game_favorite.game_id -> game.id` | 一条收藏属于一个游戏 |

V1 在 SQL 中先使用普通索引和唯一索引表达关系，暂不强制添加物理外键，方便个人开发阶段调试、导入和重建测试数据。

## 初始数据

`sql/02-init-data.sql` 初始化以下基础数据：

- 默认管理员：账号 `admin`，初始密码 `admin123456`，SQL 中保存 bcrypt 哈希
- 基础游戏分类：动作、角色扮演、射击、策略、冒险、独立游戏、体育、模拟经营、恐怖、竞速
- 基础游戏平台：PC、Steam、PlayStation、Xbox、Nintendo Switch、Android、iOS

默认管理员密码仅用于本地初始化，正式环境上线前必须替换为安全密码和新的加密哈希。
