# GameRate 游戏评分社区

## 项目简介

GameRate 是一个面向游戏玩家的游戏评分、评论、排行榜、收藏和讨论社区。用户可以浏览游戏信息、查看游戏评分、发表评价、收藏游戏，并通过排行榜发现热门或高评分游戏。

本项目是个人开发项目，目标是作为 Java 后端项目经验、全栈项目练习和后续简历展示项目。当前阶段优先完成 V1 版本，不追求一次性做成大型社区。

## 核心功能

- 用户注册、登录、退出登录。
- 游戏列表、游戏详情、分类、标签、平台筛选。
- 游戏评分、修改评分、删除评分和平均分统计。
- 游戏评论、评论分页、删除评论。
- 游戏收藏、取消收藏、我的收藏列表。
- 高评分、热门评论、最新发布、收藏数排行榜。
- 后台管理游戏、分类、标签和评论。
- Web 端基础页面。
- 微信小程序端前期预留。
