# GameRate 游戏评分社区

## 项目简介

GameRate 是一个游戏评分社区项目，规划包含 Spring Boot 后端、Web 用户端、Web 管理后台和微信小程序端。

## 当前状态

当前仅完成基础目录框架初始化，暂未实现完整业务功能。

## 项目结构

```text
gamerate-backend   Spring Boot 后端项目
gamerate-web       Web 用户端项目
gamerate-admin     Web 管理后台项目
gamerate-mini      微信小程序端项目
docs               项目文档
sql                数据库脚本
```
